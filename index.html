Setup Instructions

Follow these steps:

  1. Download Node.js and Java.
  2. Download Platinum Launcher.
  3. Unzip the launcher ZIP file.
  4. Drag the PlatinumLauncher folder to your Desktop.
  5. Open Terminal.
  6. Paste the command below.
xattr -rd com.apple.quarantine ~/Desktop/PlatinumLauncher && cd ~/Desktop/PlatinumLauncher && npm start
