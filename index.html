Platinum Launcher

Follow these steps to play Minecraft 1.21.1 on macOS

1. DOWNLOAD LAUNCHER (ZIP)
2. Install Requirements
You must install Node.js and Java 21 first.
3. Fix "App Damaged" & Start
Extract the ZIP to your Desktop. Open Terminal and paste this entire command: sudo xattr -rd com.apple.quarantine ~/Desktop/PlatinumLauncher && cd ~/Desktop/PlatinumLauncher && npm start

⚠️ You will need to type your Mac password after hitting Enter (you won't see dots as you type).

Note: This removes the macOS "Quarantine" tag so Electron can run.
