Platinum Launcher

Step 1 — Download Launcher

Download Platinum Launcher

Step 2 — Install Requirements

Download Node.js
Apple Silicon Intel Mac

Step 3 — Start Launcher

Extract the ZIP to Desktop and run:

xattr -rd com.apple.quarantine ~/Desktop/PlatinumLauncher && cd ~/Desktop/PlatinumLauncher && npm start

Mods

X-Ray Resource Pack

Place the resource pack inside the resourcepacks folder and enable it in Minecraft settings.

OneBlock World

Place the downloaded world in the saves folder.

Supported Files

  • Resource Packs
  • Datapacks
  • Shaders
  • Custom Worlds

.jar mods are not supported.
