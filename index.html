Setup Instructions

Follow these steps carefully to start the launcher:

  1. Download all required files (Node.js, Java, Platinum Launcher).
  2. Unzip the PlatinumLauncher.zip file.
  3. Drag the PlatinumLauncher folder to your Desktop.
  4. Open Terminal.
  5. Paste the command below.
xattr -rd com.apple.quarantine ~/Desktop/PlatinumLauncher && cd ~/Desktop/PlatinumLauncher && npm start

Mods

X-Ray Resource Pack

Place the X-Ray pack inside the resourcepacks folder and enable it in Minecraft settings.

OneBlock World

Place the downloaded world in the saves folder.

Supported Files

  • Resource Packs
  • Datapacks
  • Shaders
  • Custom Worlds

.jar mods are not supported.
