Platinum Launcher

Step 1: Download Launcher

Download Platinum Launcher

Step 2: Install Requirements

Download Node.js
Apple Silicon Intel Mac

Step 3: Start Launcher

Extract the ZIP to your Desktop and run this command in Terminal:

xattr -rd com.apple.quarantine ~/Desktop/PlatinumLauncher && cd ~/Desktop/PlatinumLauncher && npm start

Why Use Platinum Launcher?

  • Extremely simple setup
  • Fast Minecraft launching
  • Works with many mods and worlds
  • No complicated installation
  • Beginner friendly

Using Mods

X-Ray Resource Pack

Download the X-Ray resource pack and place it inside the resourcepacks folder in Minecraft. Then enable it in Minecraft settings.

OneBlock World

Download the OneBlock world file and place it in the saves folder. The world will appear automatically when you open Minecraft.

Supported Files

  • Resource Packs
  • Datapacks
  • Custom Worlds
  • Shaders

Note: .jar mods are not supported.

How Easy It Is

Most mods just require placing files in the correct folder. After that simply launch Minecraft and enable them in settings.
