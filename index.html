Platinum Launcher

Step 1 — Download Launcher

Download Platinum Launcher

Step 2 — Install Requirements

Download Node.js
Apple Silicon Intel Mac

Step 3 — Start Launcher

Extract the ZIP to your Desktop and run this command in Terminal:

xattr -rd com.apple.quarantine ~/Desktop/PlatinumLauncher && cd ~/Desktop/PlatinumLauncher && npm start

Why Use Platinum Launcher?

  • Extremely simple setup
  • Beginner friendly
  • Fast Minecraft launching
  • Works with many mods and worlds
  • No complicated installation

Using Mods

X-Ray Resource Pack

Download the X-Ray resource pack and place it inside your resourcepacks folder. Then enable it in Minecraft settings.

OneBlock World

Download the OneBlock world and place it in the saves folder. When you open Minecraft the world will appear automatically.

Other Supported Files

  • Resource Packs
  • Datapacks
  • Shaders
  • Custom Worlds

Note: .jar mods are not supported.

How Simple It Is

Most mods only require placing files in the correct Minecraft folder. After that launch Minecraft and enable them in the game settings.
